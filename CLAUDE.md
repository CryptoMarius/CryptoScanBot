# Claude Code – Project Preferences

## Communication language
- **Always speak Dutch** when communicating with the user in chat.
- Never switch to English in chat responses, regardless of what language the user writes in.

## Language in source code
- **Always use English** for all comments, XML doc comments, variable names, and any other text in source files.
- Never write Dutch (or any other language) text inside source code.

## Editing existing files
- When modifying an existing file, **always leave existing comments and commented-out code intact**.
- Do not remove, rewrite, or clean up comments or disabled (`//`) code blocks that were already there.
